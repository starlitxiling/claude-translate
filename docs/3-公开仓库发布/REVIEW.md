# 提交前审查

## 范围与方式

本轮只修改 Git 忽略规则和发布文档，按 review-loop 默认三角度进行独立只读审查，使用本地 Codex CLI 的 gpt-5.6-terra / medium。审查进程不读取真实密钥、不访问远端、不执行发布。

## 发现与处理

缺陷扫描指出项目级 Claude 私有配置需要显式保护。新增 .claude/.gitignore，忽略 settings.local.json 及其点号后缀备份，共享 settings.json 保持可提交。

在独立真实 Git 仓库中禁用全局 excludes 并清空 info/exclude，验证 32 个应忽略路径、14 个可提交路径，全部通过；当前已跟踪源码和测试样本没有被新规则误忽略。

## 结论

三个角度复审均为 clean，无遗留高置信 correctness 问题。主会话另行扫描完整 Git 历史和最终提交内容，检测真实已知凭据及常见密钥格式；该检查不把凭据值写入日志或仓库。
