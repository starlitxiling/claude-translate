# 实现计划

1. 增加独立的命令接管组件，将现有 `~/.local/bin/claude` 原生符号链接保存为可恢复状态，再原子替换为启动脚本。保留 `claude-original` 指向同一个原生二进制。
2. 启动脚本显式传递原生二进制路径，避免翻译启动器再次从 PATH 找到自己而递归。原生帮助、版本和管理子命令直接调用原二进制；聊天走既有翻译链路。
3. 提供 `claude-translate enable` 和 `claude-translate disable`。重复启用/停用应安全；停用前核对启动脚本仍由本组件管理，不覆盖其他工具或用户后续修改。
4. 先用真实文件、符号链接及本机真实 Claude 二进制测试启用、停用、重复操作和冲突，再实现。运行原有测试和直接 `claude` 的真实翻译验收。审查后本地提交，不推送。
5. 后续工具命令明确以项目目录为工作目录。Codex 会话级目录由官方 `/cd` 控制，只能在主会话空闲时切换；若当前工具没有该入口，给出准确的剩余操作，不能把单次 shell 的 cwd 当作会话已迁移。

## 关键边界

原生版本仍为用户授权安装的 2.1.299。翻译设置和运行时依赖继续分离。不覆盖原生二进制，不改凭据。源码项目保持 `/Users/wujie/Work/claude-translate`，本轮在独立 worktree 开发。
