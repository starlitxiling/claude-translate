# 提交前审查

## 审查方式

按 review-loop 重档五角度执行独立 context 审查，使用 codex-subagent 的本地 Codex CLI。四个常规角度为 gpt-5.6-terra / medium，并发与生命周期角度为 gpt-5.6-sol / high；只读、不调用付费 API、不读取密钥。

## 发现与处理

前四个角度首轮 clean。并发角度发现：连续 128 个前台报告翻译失败后，失败终态不能淘汰，导致新代理报告被一直忽略。

处理：增加 completed 状态，前台完成时无论译文成功与否都进入可淘汰终态，仅在无使用者时淘汰；后台待交接/重试状态继续保留。真实长度校验失败填满状态槽的回归先红后绿，随后新报告可以正常显示。

另核对真实 Handback 的主会话输入封装，将已登记代理的 `<agent-message>` 与后台 `<task-notification>` 一并直接传递，不送入人类输入翻译。新增真实捕获事件回归通过。

## 复审与验证

五个角度复审均为 clean，没有遗留高置信 correctness finding。两个 reviewer 独立运行了 14 个离线回归；其他运行验证受只读沙箱缓存权限限制，未独立复跑真实 API。

主会话最终全套 65 项测试通过，包含真实 Claude 的前台、后台和 auto 模式 SubagentHandback；全部使用真实组件，无 mock/stub/fake。Ruff、格式检查及安装后默认命令验证通过。
